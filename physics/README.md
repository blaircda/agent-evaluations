# Agent Evaluations: Physics 

## Reading and reporting on papers

Here I'm tasking agents to read a scientific paper (on string theory) and produce a report detailing:

1) the principal success, 2) the principal drawback, 3) a recommended next research direction balancing feasibility and impact

After running a variety of models on different effort levels, another agent produces a summary file breaking down what's recommended.

From this you can observe qualitative differences between different models, as well as getting potentially useful research feedback.

### Template
[Template](research-paper-template)

Contents:

```AGENTS.md``` instructions for the agents

```config.py``` sets models, effort levels, number of agents, files to use

```paper.tex``` replace with your own tex file

```run_agent_check.py``` script which runs agents to write reports on ```paper.tex``` and outputs a summary of the run data and (using another agent) a summary of the reports
