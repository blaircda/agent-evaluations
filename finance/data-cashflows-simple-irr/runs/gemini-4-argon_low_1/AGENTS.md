# Goal
Compute the Internal Rate of Return (IRR) for a set of cashflow streams.

# Input data
The file data.csv.
Each line of this file contains a cashflow stream.

## Instructions
Calculate the IRR for each stream in data.csv, expressed in decimal format to six decimal places. Save the results to results.csv. Write each IRR on its own line, so the IRR corresponding to the cashflow on line 1 of data.csv appears on line 1 of the results csv file, the IRR corresponding to the cashflow on line 2 of data.csv appears on line 2 of the results file, and so on.

If you use a Python script to calculate the IRR, save the exact code you used to compute the results as method.py in the working directory. Run from the working directory, it must read data.csv and write results.csv using relative paths.
If you use an alternative method, create method.txt with an explanation of your method. 

Do nothing else.
