# Agent Evaluations: Data/coding for finance

See the [main README](main README) for the summary of the results of these experiments.

## Task: calculating internal rates of return for cashflow streams

The basic format here is providing different models with some data and a desired calculation to be performed on the data, and then recording what method or methods they use to perform the calculation.
This initial experiment is kept deliberately simple.

### Template
[data-template](data-template)

Contents:

`AGENTS.md` instructions for the agents

`data.csv` input data, replace with your own data file

`master_results.csv` target output data, replace with your own data file 

`config.py` sets models, effort levels, number of agents, files to use

`adapters.py` parses different jsonl log files (currently for Claude and Gemini output)

`launch_agent_grid.py` script which runs agents to do a computation based on `data.csv`. The outputs of `launch_agent_grid.py` are:
> - `logs/` (not included here) JSON lines log files with the output streams of each agent run
> - `runs/` a directory for each agent run, named according to the model and effort level, containing a copy of `AGENTS.md` and `data.csv` and the agent output
> `summary.csv` data summary: model, effort, time, output tokens,...
> `summary.txt` agent text output summary, extracted from the logs

`launch_agent_check.py` script for checking aspects of the agent output, in particular (with appropriate modifications depending on the specific task and data set) allowing for checking their output data against the target `master_results.csv` and for verifying that code produced by the agents does actually produce the claimed data

`launch_summary_agent.py` script which runs a single agent to (depending on the prompt provided) analyse the methods used by the agents. The outputs of `launch_summary_agent.py` may include:
> - modifying `summary.csv` with extra information
> `summary.md` an agent-genreated report
> - an extra log file saved to `logs/` (not included here) 


### Experiment 1: Simple flows
[data-cashflows-simple-irr](data-cashflows-simple-irr)

The `data.csv` provided conists of simple cashflows generated by `finance_methods.py`, with initial negative outlay and subsequent positive inflows.
The scripts are as in the template.
The instructions in `AGENTS.md` ask the agents to calculate the internal rate of return (IRR) of the flows, specify the output data format, and say if they use Python to save their script as `method.py`, or else write `method.txt` explaining what they did (in the end, they all naturally use Python).
The `launch_summary_agent.py` prompt asks for an agent classification of method used, further method details, how the code treats failure, and whether commented descriptions match what the code actually does.

### Experiment 2: Mixed flows
[data-cashflows-mixed-irr](data-cashflows-mixed-irr)

The `data.csv` provided conists of mixed cashflows generated by `finance_methods.py`, consisting of the simple flows from experiment 1 concatenated with some further randomly generated flows with arbitrary signed flows, having none, 1 or 2 possible IRRs.
The scripts are as in the template.
The instructions in `AGENTS.md` ask the agents to calculate the internal rate of return (IRR) of the flows, specify the output data format, and say if they use Python to save their script as `method.py`, or else write `method.txt` explaining what they did (in the end, they all naturally use Python). This is the same prompt as in Experiment 1, so in particular it does not tell them what to do with cases with no or multiple IRRs.
The `launch_summary_agent.py` prompt asks for an agent classification of method used, further method details, how the code treats failure, whether commented descriptions match what the code actually does, and additionally how they treat cases with multipe IRRs.
